# @blitzd/resizable-panels

A monorepo for headless, animated, resizable panel primitives for React.

[Documentation](https://resizable-panels.blitzd.dev)

## Development

Requires [Bun](https://bun.sh/).

```sh
bun install
bun run dev
```

## Commands

```sh
bun run build       # Build the library and demo
bun run test        # Run unit tests
bun run typecheck   # Typecheck all workspaces
bun run lint        # Check with Biome
bun run lint:fix    # Apply Biome fixes
```

The library is in `packages/resizable-panels`. The demo is in
`apps/demo`.

See the [library README](packages/resizable-panels/README.md) for
usage.
